Incredible — a MekoSix type family
==================================

Two weights:
  Incredible Regular  1.000  (235 glyphs)
  Incredible Bold     1.005  (215 glyphs)

Files
-----
otf/    Desktop fonts for macOS, Windows and Linux.
woff2/  Web fonts for @font-face.
specimen.html  A specimen and live type tester. Open it in any browser.

Install
-------
macOS:   Double-click the OTF files and choose "Install Font", or open
         Font Book and drag them in.
Windows: Right-click an OTF and choose "Install", or "Install for all users".

Both weights share the family name "Incredible", so Regular and Bold pair in
font menus. The two source cuts use slightly different vertical metrics, so
line height can shift a little when you mix them in the same paragraph.
